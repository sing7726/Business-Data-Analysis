# Logistics Database Analysis using Excel

This project is an Excel-based logistics and warehouse operations analysis built to study inventory management, stockout risk, reorder priority, fulfillment performance, and warehouse productivity.

The workbook contains a logistics dataset with more than 3,200 inventory records. Excel formulas, Pivot Tables, summary sheets, and dashboard visuals were used to convert raw warehouse data into useful business insights.

## Project Objective

The main objective of this project is to analyze warehouse inventory and logistics performance using Excel. The project focuses on identifying low-stock items, products at risk of stockout, high-value inventory categories, warehouse zone performance, and items that should be reordered first.

## Key Features

- Cleaned and structured logistics inventory dataset
- Calculated stock status for each item
- Identified items with stockout risk
- Calculated days of inventory left
- Calculated total inventory value
- Estimated monthly holding cost
- Analyzed fulfillment performance
- Analyzed picking speed and warehouse zone efficiency
- Created Pivot Table summaries
- Built a dashboard for quick business insights
- Created reorder priority analysis for urgent inventory decisions

## Workbook Sheets

### 1. logistics_dataset
Main dataset containing item-level warehouse and inventory information, including stock level, reorder point, lead time, daily demand, zone, picking time, unit price, fulfillment rate, and calculated KPI columns.

### 2. Pivot_Tables
Summary Pivot Tables showing category-wise inventory, stockout risk, stock status, warehouse zone performance, reorder priority, and fulfillment performance.

### 3. Category_Analysis
Category-level analysis comparing total stock, inventory value, monthly holding cost, average fulfillment rate, and stockout risk.

### 4. Zone_Analysis
Warehouse zone analysis based on picking time, layout efficiency, KPI score, and fulfillment rate.

### 5. Reorder_Priority
Top items that require reorder attention based on stock level, reorder point, stockout risk, and days of inventory left.

### 6. Dashboard_v2
Final dashboard summarizing important logistics KPIs and business insights.
